# Analytics Dashboard with Live Chart Updates

## Project Overview
This is a responsive analytics dashboard that displays real-time business metrics such as users, revenue, feature usage, and user segmentation.

## Features
- KPI Cards (Total Users, Revenue, Active Users, Growth Rate)
- Line Chart (Revenue Trends)
- Bar Chart (Feature Usage)
- Pie Chart (User Segmentation)
- Real-time API polling (every 30 seconds)
- CSV Export functionality
- Fully responsive UI

## Tech Stack
- HTML
- CSS
- JavaScript
- Chart.js
- Axios

## Project Structure
- index.html
- style.css
- app.js
- charts.js
- api.js
- export.js

## How to Run
1. Clone the repository
2. Open project in VS Code
3. Run with Live Server
4. Dashboard will start working
